## 6. Data quality / methodology

- **Point-in-time data:** ALFRED vintages; SEC filing dates; exchange timestamps; `knowledge_time` joins.
- **Survivorship:** include delisted stocks/coins; PIT index membership; delisting returns.
- **Wash trading:** Cong et al. (2022); prefer regulated venues for volume/liquidity.
- **Corporate actions:** adjusted vs unadjusted prices; verify with a second source.
- **Time zones:** store UTC; use exchange calendars; handle DST.
- **Reproducibility:** DVC/checksums, git commit, environment lock, deterministic seeds.

## 7. How this research was conducted

- **Primary documentation** fetched directly from vendor/exchange/broker sites (pricing, API limits, licenses).
- **Academic metadata** verified via OpenAlex and Crossref (DOIs, titles, years, citation counts).
- **Repository metadata** (stars, license, last push) via GitHub API on 22 Oct 2026.
- **Package versions** via PyPI JSON on 22 Oct 2026.
- **Framework capabilities** from official docs and READMEs, not blog summaries.
- **Performance claims** were not taken from marketing pages; strategy evidence is from peer-reviewed papers and is presented with caveats.

### Limitations

- Prices and rate limits change frequently; verify before purchase.
- Academic results are gross of many real-world costs and may not replicate.
- GitHub stars measure popularity, not correctness.
- Crypto data quality is materially worse than US equity data.
- No backtest in this report is a recommendation to trade.
